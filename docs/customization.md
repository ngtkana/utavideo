# カスタマイズ一覧

「これを変えたい」ときに、どこをどう書けばよいかの一覧です。基本の手順は [workflow.md](workflow.md)、設定項目の型と既定値は [config-reference.md](config-reference.md) を参照してください。

## 変えられる場所

| 場所 | 変えられるもの |
|---|---|
| 曲の `utavideo.toml` | 曲名・音源・背景・解像度・画質・フェード・曲名表示 |
| 歌詞の `.ass` | 歌詞と曲名表示の見た目（フォント・大きさ・色・位置・縁取り）、行ごとの演出 |
| ユーザー設定 `~/.config/utavideo/config.toml` | フォントを探す場所（すべての曲に共通） |
| 環境変数 | フォントを探す場所、設定・キャッシュの場所 |
| コマンドのオプション | 曲フォルダの指定（`-C`）、`release` のバージョン |

## 歌詞の見た目

見た目は .ass のスタイルで決めます。Aegisub のスタイルマネージャで変えると、プレビュー動画の上ですぐに確認できます。

### スタイル

| やりたいこと | スタイルの項目 |
|---|---|
| フォント・大きさ | `Fontname`・`Fontsize`（PlayRes の座標での px） |
| 文字の色・縁の色・影の色 | `PrimaryColour`・`OutlineColour`・`BackColour`（`&HAABBGGRR`。AA は透明度で `00` が不透明） |
| 太字・斜体 | `Bold`・`Italic`（`-1` で有効） |
| 縁取り・影の太さ | `Outline`・`Shadow` |
| 文字の後ろに四角い帯を敷く | `BorderStyle` を `3` にする（帯の色は `OutlineColour`） |
| 字間・横幅 | `Spacing`・`ScaleX` |
| 位置 | `Alignment`（テンキーの配置。`2` が下中央、`8` が上中央、`7` が左上）と `MarginL`・`MarginR`・`MarginV` |

位置が何種類かあるときは、`LyricsLeft`・`LyricsRight` のようにスタイルを分けます。行ごとにタグで位置を変えるより、後からまとめて直しやすくなります。

### 行ごとのタグ

libass が対応する上書きタグ（`\an`・`\c`・`\blur`・`\t` など）はそのまま使えます。そのうち次のタグは、utavideo の検査や加工にも影響します。

| タグ | utavideo での扱い |
|---|---|
| `\fad`・`\fade` | その行には自動のフェード（`lyrics.fade_ms`）を付けない |
| `\pos`・`\move` | `check` が行数を警告する。重なりとはみ出しの検査からは外す |
| `\fn` | そのフォントも探す対象になり、見つからなければエラー |
| `\r<スタイル名>` | 切り替え先のスタイルも、未定義ならエラー。フォントも探す対象になる |
| `\fs`・`\fscx`・`\fsp` | はみ出しの概算に反映する |
| `\q` | 折り返しの方式として、はみ出しの概算に反映する |
| `\N`・`\n`・`\h` | 改行・固定幅の空白として、はみ出しの概算に反映する |

はみ出しの概算は、`\bord`（縁取りの太さの変更）と縦書き（`@` 付きのフォント名）を反映しません。

### 同時に複数の行を出す

ハモリや掛け合いなどで同じスタイルの行を同時に出すときは、Aegisub で**レイヤーを分けます**。`check` は同じスタイル・同じレイヤーで時間が重なる行を警告します。レイヤーが違えば警告は出ません。

```
Dialogue: 0,0:00:10.00,0:00:13.00,Lyrics,,0,0,0,,主旋律の歌詞
Dialogue: 1,0:00:10.00,0:00:13.00,Lyrics,,0,0,0,,{\an8}ハモリの歌詞
```

レイヤーの数字が大きい行ほど手前に描かれます。曲名表示はレイヤー 100 に入ります。

### 書き出さないメモを残す

Aegisub で行を「コメント」にすると、書き出しにも検査にも使われません。構成のメモや、歌詞の候補を残しておくのに使えます。

### 折り返し

libass は空白の位置でしか自動で折り返さないので、空白の無い日本語の長い行は `\N` で改行します。
折り返しの方式は、.ass の `[Script Info]` の `WrapStyle`（ファイル全体）か、行ごとの `\q` で変えられます。

### フェード

| やりたいこと | 書き方 |
|---|---|
| 全行のフェードの長さを変える | `utavideo.toml` の `lyrics.fade_ms = [イン, アウト]`（ミリ秒） |
| フェードを付けない | `lyrics.fade_ms = [0, 0]` |
| 特定の行だけ変える | その行に `\fad(イン,アウト)` を書く（自動のフェードは付かなくなる） |

## 曲名表示

動画の最初から最後まで、レイヤー 100 に1行入ります。自動のフェードは付きません。

| やりたいこと | 書き方 |
|---|---|
| 見た目・位置を変える | .ass の `Title` スタイルを変える |
| 別のスタイルを使う | `overlay_text.style = "スタイル名"`（.ass に無いとエラー） |
| 文字を変える | `overlay_text.text`。`{title}`・`{artist}`・`{label}` が使える |
| 改行する | `\N`。TOML では `"\\N"` と書く |
| 上書きタグを使う | `{` `}` を二重にする。例: `text = "{{\\an7}}{title}\\N{artist}"`（左上に2行で表示） |
| 表示しない | `overlay_text.enabled = false`（`Title` スタイルのフォントも不要になる） |

`text` の `{名前}` は置き換えの印なので、上書きタグの `{\an7}` をそのまま書くとエラーになります。

## 背景と映像

| やりたいこと | 書き方 |
|---|---|
| 背景を画像・GIF・動画にする | `video.background`。GIF と動画は音声の長さまで繰り返す。動画の音声は使わない |
| 縦横比が違う背景を切り取る / 余白を付ける | `video.fit = "cover"` / `"contain"`、余白の色は `video.pad_color` |
| ドット絵をくっきり拡大する | `video.scale_flags = "neighbor"` |
| フレームレートを変える | `video.fps` |
| 画質を上げる / 書き出しを速くする | `video.crf`（小さいほど高画質）・`video.preset`（`"fast"` などで速くなる） |

### 解像度を変える・縦長の動画にする

`video.size` と、.ass の `PlayResX`・`PlayResY` を同じ値にします（どちらも偶数）。違うと `check` がエラーにします。

```toml
[video]
size = [1080, 1920]
```

既に歌詞を入れた .ass の解像度を変えるときは、Aegisub の「解像度の変換（Resample Resolution）」を使うと、スタイルの大きさや余白も一緒に拡大縮小されます。

## 音源とバージョン

- `audio.file` は ffmpeg が読める形式なら使えます。`init` が自動で設定するのは wav / flac / mp3 / m4a / aac / ogg / opus だけです
- 音源のファイル名に含まれる `v` と数字（`v1`、`v1.2`、`V1.2.3`）がバージョンになります。複数あれば最後のものを使い、`v1.2a` のように英数字が続くものはバージョンとみなしません
- `utavideo release --version v1.2.1` でバージョンを指定できます（小文字の `v` で書く）
- `build/main.mp4` より新しい入力があっても公開用にコピーしたいときは `--allow-stale` を付けます

## フォント

### 探す場所

| やりたいこと | 書き方 |
|---|---|
| すべての曲で探す場所を変える | ユーザー設定の `font_dirs = ["~/fonts", ...]`（既定の場所は探さなくなる） |
| その場だけ探す場所を変える | 環境変数 `UTAVIDEO_FONT_DIRS`（`:` 区切り。`font_dirs` より優先） |
| 曲フォルダに入れたフォントを使う | 曲フォルダで `UTAVIDEO_FONT_DIRS=./fonts utavideo build`（相対パスはコマンドを実行した場所から） |

Aegisub で同じ見た目を確認するには、Aegisub を動かす環境にもそのフォントをインストールしてください。

### 名前の照合

スタイルや `\fn` のフォント名は、フォントファイルの中のファミリー名・フルネーム・PostScript 名・タイプグラフィック・ファミリー名のどれかと、大文字小文字を区別せずに照合します。同じ名前のファイル（太さ違いなど）はすべて libass に渡され、太字かどうかは libass が選びます。名前の先頭の `@`（縦書き）は取り除いて探します。

### キャッシュ

フォントの一覧は `~/.cache/utavideo/fonts.json`、libass に渡すフォントの組は `~/.cache/utavideo/fontsets/` に置かれます。消しても次回作り直されます。

## 曲フォルダとファイルの置き場所

- `utavideo.toml` のパスは、`utavideo.toml` からの相対パスか絶対パスで書きます。歌詞の .ass も `lyrics.file` で別の場所を指定できます
- utavideo が読むのは `utavideo.toml` で指定したファイルだけなので、`src/` の中の分け方は自由です
- コマンドは、カレントディレクトリから親へ向かって `utavideo.toml` を探します。曲フォルダの外からは `-C <曲フォルダ>` で指定します

## 雛形を自分用にする

`new` / `init` が書き出す雛形の中身は、今は設定では変えられません。自分の定番のスタイルを使い回すには、次のどちらかを使います。

- Aegisub のスタイルマネージャで、スタイルをストレージに保存しておき、新しい曲の .ass にコピーする
- 自分用の `src/lyrics.ass` などを入れたフォルダを曲ごとに複製し、`utavideo init <フォルダ>` を実行する（既にあるファイルはそのまま残り、足りないものだけが作られる）

## 動画編集ソフトと組み合わせる

utavideo で合成できない演出は、`utavideo overlay` で歌詞と曲名表示だけの透過動画（ProRes 4444）を書き出し、動画編集ソフトで重ねます。手順は [workflow.md の「動画編集ソフトと組み合わせる」](workflow.md#動画編集ソフトと組み合わせる) を参照してください。

## 実際に描画した内容を確かめる

`build/.work/` に、書き出しに使った .ass（`final.ass`・`preview.ass`・`overlay.ass`）が残ります。自動のフェードと曲名表示の行が入った状態なので、Aegisub で開いて、何が描かれたかを確かめられます。

## 環境変数

| 変数 | 内容 |
|---|---|
| `UTAVIDEO_FONT_DIRS` | フォントを探す場所（`font_dirs` より優先） |
| `XDG_CONFIG_HOME` | ユーザー設定の場所（既定は `~/.config`。`utavideo/config.toml` を読む） |
| `XDG_CACHE_HOME` | キャッシュの場所（既定は `~/.cache`） |
| `XDG_DATA_HOME` | `font_dirs` の既定値に含める `fonts/` の場所（既定は `~/.local/share`） |

## 今は変えられないもの

- 出力の形式（コーデック・音声のビットレート・プレビューの画質）。一覧は [config-reference.md](config-reference.md#書き出しの設定変更不可)
- 曲名表示の表示区間・レイヤー・フェード、要素を2つ以上にすること
- 背景を2枚以上重ねること、アバターの合成（[ロードマップ](roadmap.md)）
- 1曲に使える .ass は1つだけ
