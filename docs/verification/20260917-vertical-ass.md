# 2026-09-17 縦用 .ass の雛形（vertical-ass）

縦型のショート（issue #22）の1段目、`utavideo vertical-ass` と `LayoutResX`・`LayoutResY` の検査の前提にした、libass と pysubs2 の挙動の記録。

## 環境

- ffmpeg 6.1.1（Ubuntu 24.04 のパッケージ、libass 付き）。WSL2 で実行
- pysubs2 1.9.0
- フォントは DejaVu Sans。背景は `lavfi` の `color=black`。`subtitles` で描いてから `format=gray` にし、輝度 128 を超える画素の範囲を測った

## LayoutRes と文字の幅

PlayRes 1080x1920 の .ass に、`DejaVu Sans` 100px・中央揃えの `MMMM` を1行置き、`[Script Info]` の `LayoutResX`・`LayoutResY` だけを変えて、1080x1920 の映像に描いた。

| LayoutRes | 文字の幅 | 文字の高さ |
|---|---|---|
| なし | 280 | 63 |
| `1080x1920`（PlayRes と同じ） | 280 | 63 |
| `1920x1080`（本編の値が残ったもの） | 88 | 63 |
| `LayoutResX: 1920` だけ | 280 | 63 |
| `LayoutResY: 1920` だけ | 280 | 63 |
| `LayoutResY: 1080` だけ | 280 | 63 |

- 本編の `1920x1080` が残ると、縦の長さはそのままで、文字の幅が約 3 割に潰れる
- 片方だけの `LayoutRes` は、無いときと同じ（libass は2つ揃ったときだけ使う）。utavideo の検査は、2つ揃っていて PlayRes と違うときだけエラーにする
- 無いときと PlayRes と同じ値のときで、書き出しは変わらない

同じ .ass（PlayRes 1080x1920）を、大きさの違う映像に描いた。

| 映像 | LayoutRes | 文字の幅 | 文字の高さ |
|---|---|---|---|
| 1080x1920 | なし | 280 | 63 |
| 1080x1920 | `1080x1920` | 280 | 63 |
| 540x960 | なし | 140 | 31 |
| 540x960 | `1080x1920` | 140 | 31 |
| 1920x1080 | なし | 158 | 36 |
| 1920x1080 | `1080x1920` | 498 | 36 |

- 縦横比が PlayRes と同じ映像なら、LayoutRes の有無で描画は変わらない
- 縦横比の違う映像（縦用 .ass を本編の下敷きで開いたときなど）では、LayoutRes が無いと文字の縦横比を保ち、あると文字が横に伸びる

これを踏まえて、`vertical-ass` は **LayoutRes があれば縦のサイズで書き直し、無ければ足さない**。

- 消しても書き直しても、utavideo の書き出し（映像の大きさ ＝ PlayRes）の結果は同じ
- 本編の .ass の書き方（Aegisub などが書いた項目）をそのまま残し、値だけを縦に合わせる
- 間違った縦横比の下敷きで開いたときに、文字の形が崩れて気づける

## pysubs2 の読み書き

`LayoutResX`・`LayoutResY` と `[Aegisub Project Garbage]`（`Video File`・`Video AR Mode` など）を含む .ass を `SSAFile.from_string` で読み、`to_string("ass")` で書いた。

- `LayoutResX`・`LayoutResY` は `info` に入り、そのまま書かれる
- `[Aegisub Project Garbage]` は `aegisub_project` に入り、そのまま書かれる
- `[Script Info]` の `;` で始まるコメント行は残らない（`; Script generated by pysubs2` に置き換わる）

## 変換した .ass の描画

PlayRes 1920x1080 の .ass（`DejaVu Sans` 100px、字間 4、縁取り 4、余白 120・120・90、下中央揃えの `MMMM`。`\an5\pos(480,270)\fs60` の `MM`）を `vertical.convert` で 1080x1920 に変換し、それぞれの大きさの映像に描いた。

| 行 | 本編（1920x1080） | 縦（1080x1920） | 本編 × 幅の比（0.5625） |
|---|---|---|---|
| `MMMM` の幅 | 292 | 164 | 164.25 |
| `MMMM` の下端からの余白 | 110 | 62 | 61.9 |
| `\pos` の行の幅 | 82 | 46 | 46.1 |
| `\pos` の行の中心 | (477.5, 268.5) | (268.5, 479.0) | x は 268.6、y は ×1.778 で 477.3 |

- 大きさは幅の比で一様に縮み、`\pos` の位置は画面の同じ割合の場所に移る
