# 2026-09-17 告知文の生成の検証記録

## 告知ポストの調査

X で公開されている歌ってみた動画の告知ポスト約30件を、公開されている投稿のデータで調べた。

- 骨格は、見出し → 手書きの文章 → `『曲名 / アーティスト』` の作品の行 → `サイト名 » URL` のリンク → ハッシュタグ。ブロックの間を空行で空けるか詰めるかは回ごとに違った（`order` の `""` で空行を書く理由）
- 作品の行の区切り（`/`・` / `・` - `）とハッシュタグは回ごとに揺れ、中身の無い `#` が残った回があった
- サイト名のラベルと URL の組を取り違え、別の動画の URL を貼って再投稿した回があった
- 長さを twitter-text v3 の規則（下記）で数えると、280 以下のものはすべて普通の投稿、281 以上のものはすべて長文の投稿（投稿のデータの `note_tweet`）だった

## 折りたたまれる位置

長さ 342 の長文の投稿を X の Web のタイムラインで見ると、「さらに表示」に折りたたまれ、長さ 275 の位置まで表示されていた。275 は行の切れ目で、次の行を足すと 280 を超える。埋め込み用のデータで途中までになっていた本文とも一致した。

- 280 を超えると折りたたまれる。`announce.max_weight` の既定値を 280 にした
- 超えた分は 280 以内の行の切れ目までしか見えないので、末尾に置いたハッシュタグから隠れる

## twitter-text v3 の値

https://github.com/twitter/twitter-text/blob/master/config/v3.json で確認した（重みは `scale` の 100 で割った値）。

| 項目 | 値 |
|---|---|
| `maxWeightedTweetLength` | 280 |
| `defaultWeight` | 2 |
| `ranges`（重み 1） | U+0000–U+10FF、U+2000–U+200D、U+2010–U+201F、U+2032–U+2037 |
| `transformedURLLength` | 23 |
| `emojiParsingEnabled` | true（絵文字の組み合わせを1つで 2 と数える） |

twitter-text は数える前に NFC に正規化する。`announce.py` の `DEFAULT_WEIGHT`・`LIGHT_RANGES`・`URL_WEIGHT` はこの値で、`tests/test_announce.py` で各範囲の境界を確かめている。

スキームの無い URL は、npm の twitter-text 3.1.0 の `extractUrls` で確かめた。ドメインの末尾が TLD の一覧（`dist/regexp/validGTLD.js`・`validCCTLD.js`、1574 件）にあり、その後ろが英数字・`@`・`+`・`-` でないときだけ URL になる。直前が英数字・`@`・`$`・`#`・`-`・`_`・`.`・`/` のときは URL にしない。

| 文 | URL | 長さ |
|---|---|---|
| `『Mr.Children』` | なし | 15 |
| `feat.Ado`・`St.Vincent`・`utavideo.toml` | なし | 8・10・13 |
| `example.com`・`nicovideo.jp`・`nico.ms/sm1`・`example.みんな` | 全体 | 23 |
| `foo.music`（3.1.0 の一覧に無い新しい TLD） | なし | 9 |

`src/utavideo/tlds.txt` はこの一覧を書き出したもので、`announce.py` はこれで判定する。

ハッシュタグとしてつながる文字は、twitter-text の `js/src/regexp/` の `hashtagAlphaNumeric`（文字・結合文字・数字と `hashtagSpecialChars`）で、タグには文字か結合文字（`hashtagAlpha`）が1つ以上要る。`hashtagSpecialChars` は `_`、U+200C、U+200D、U+A67E、U+05BE、U+05F3、U+05F4、U+FF5E、U+301C、U+309B、U+309C、U+30A0、U+30FB、U+3003、U+0F0B、U+0F0C、U+00B7。
