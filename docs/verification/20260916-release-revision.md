# 2026-09-16 release の採番の検証記録

## 同じ入力から書き出した動画はバイト単位で一致する

`release` は、公開済みの動画と中身が同じなら止まる。これが「書き出し直しただけで番号が進む」ことを防げるのは、同じ入力からの書き出しが毎回同じバイト列になるときだけなので、確かめた。

環境は ffmpeg 6.1.1-3ubuntu5（Ubuntu 24.04、20 スレッド）。

| 測ったもの | 結果 |
|---|---|
| `utavideo build` を2回（320x180、`preset ultrafast`、テスト用の小さい曲フォルダ） | 59789 バイトで一致 |
| libx264 で直接2回（1920x1080、30fps、4秒、`preset medium`、CRF 18、AAC 320kbps） | sha256 が一致 |
| 同上（`preset slow`。`video.preset` の既定値） | sha256 が一致 |

x264 はスレッドを使っても、同じ設定・同じ入力なら同じ出力になる。

ffmpeg のバージョンやビルドが変われば一致しなくなりうるが、そのときは番号が1つ余計に進むだけで、上書きや消失は起きない。
